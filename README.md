# ChatGPT Demo — Static Chat UI

A pixel-accurate recreation of the ChatGPT interface built with **Vite + React**. Fully static with mock data — no backend or API required.

## Features

- **Sidebar** with conversation list, new chat, delete, open/collapse toggle
- **Chat area** with message bubbles, markdown rendering, code blocks
- **Typing indicator** with animated dots during mock AI responses
- **Responsive design** — sidebar collapses to overlay on mobile
- **Empty state** with suggestion cards
- **Dark theme** matching the ChatGPT aesthetic

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

## Tech Stack

- React 19
- Vite 6
- Pure CSS (no external libraries)
